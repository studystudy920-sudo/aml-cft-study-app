# CAMS 問題データセット（AML/CFT 学習アプリ用）

CAMS（公認AMLスペシャリスト）試験対策の問題データです。公式構造（4ドメイン / 16サブカテゴリ・**計750問**）に沿って構成されています。

## ファイル

| ファイル | 内容 | 件数 |
|---|---|---|
| `questions_v4.json` | 全問データ（問題＋選択肢＋正解＋解説を統合した自己完結型） | 750 |
| `answers_v4.json` | 正解・解説のみを id キーで引ける形式（v3互換） | 750 |

## 出自（どう作ったか）

全750問を、Google Drive の「CAMS問題」プロジェクト（公式構造のテーマ別デッキ群 .pptx）から抽出・構造化しました（`source: "deck_extract"`）。各デッキのスライドから問題文・選択肢・正解・解説（空-雨-傘＋選択肢別根拠）を抽出しています。

> 旧版（834問）は、ドメイン1・2・3-1 を古い `462問.md`（v3）由来で持っていたため、公式構造より84問多くなっていました。本版ではその部分も公式デッキから抽出し直し、全16サブカテゴリを公式件数に一致させています。

## スキーマ（`questions_v4.json` の各レコード）

```json
{
  "id": 1,
  "domain": 1,
  "folder": "1/1",
  "theme": "01_3段階モデル（呼称_段階の概念）",
  "question": "問題文（日本語）",
  "choices": ["選択肢1", "選択肢2", "..."],
  "answer": "正解（レター＋正解テキスト。複数選択は「B・D …／…」形式）",
  "explanation": "解説（空-雨-傘形式の要約＋選択肢別根拠）",
  "points": [],
  "imgs": [],
  "source": "deck_extract"
}
```

- `theme`: 抽出元デッキのテーマ名（番号＋名称）。
- `points` / `imgs`: 本版では全件空配列。
- `answer`: 「レター＋正解テキスト」。複数選択は記号を `・` で連結し、本文を `／` で連結。
- `answers_v4.json`: `{"<id>": {"id", "answer", "explanation", "points"}}` のオブジェクト形式。

## 既知の注意点（データ品質）

- **正解・解説はAI生成**。元デッキの脚注に「※正解・解説・図解はAI生成。最終確認を推奨」とあり、権威ある公式キーではありません。利用時は最終確認を推奨します。
- デッキの各スライドに付く「Qn/5」などのページ番号は実際の問題数と一致しないことがあり、抽出時は各デッキの目次と実際の「正解」ブロックで真の件数を確定しています。結果として全16サブカテゴリが公式件数に一致しています。
- 一部の問題で、英語ラベルの「(Select two/three)」と日本語設問・実際の正解数が食い違うケースがあり、その場合は**解説スライドの実際の正解**を採用しています。
- 設問文が同一の重複が3組あります（id 135/139、277/279、312/313）。これらは元デッキ内に実在するスライド（選択肢の並び替えを含むドリル的反復）に由来し、公式件数を維持するため保持しています。
