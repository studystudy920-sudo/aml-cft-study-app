## スキーマ（`questions_v4.json` の各レコード）

```json
{
  "id": 1,
  "domain": 1,
  "folder": "1/1",
  "theme": null,
  "question": "問題文（日本語）",
  "choices": ["選択肢1", "選択肢2", "..."],
  "answer": "正解（テキスト。抽出分はレター付きの場合あり）",
  "explanation": "解説（v3は詳細文、抽出分は空-雨-傘形式の要約）",
  "points": ["学習ポイント", "..."],
  "imgs": ["IMG_0316", "..."],
  "source": "v3"
}
```

- `theme`: デッキ抽出分のみテーマ名を保持（v3分は `null`）。
- `points`: v3分のみ（学習ポイント配列）。抽出分は空配列。
- `imgs`: v3分のみ（元キャプチャの画像参照）。抽出分は空配列。
- `answer`: v3分は正解テキスト、抽出分は「レター＋正解テキスト」の形式が混在。

## 既知の注意点（データ品質）

- **正解・解説の一部はAI生成**。元デッキの脚注に「※正解・解説・図解はAI生成。最終確認を推奨」とあり、権威ある公式キーではありません。利用時は最終確認推奨。
- 一部の抽出問題で、英語ラベルの「(Select two/three)」と実際の正解数が食い違うケースがあり、その場合は**解説スライドの実際の正解**を採用し、`explanation` 内に注記しています。
- 公式の問題数（750問）は試験ブループリントの**配点比重**であり、デッキ実体の問題数（834問）とは一致しません。
